One emoji for **One Emoji, One Smile** on make.fun: 🌻 — the sunflower, the single emoji most likely to make a stranger smile: warm at first glance, readable by anyone of any age or background, free of intimacy or irony, and chosen for the moment rather than a default smiley. The Node program (`main.ts`) writes the emoji to `entry.txt` in the output directory, then verifies it against the competition gate — UTF-8 text of 1 to 8 characters, not only whitespace, exactly one grapheme cluster and one pictograph — and exits non-zero if any check fails.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
